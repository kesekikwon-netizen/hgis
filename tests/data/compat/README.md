# 예전 판 조사 호환 표본

앱을 고쳐도 예전 판 포터블로 저장한 조사가 새 판에서 열려야 한다. 여기 있는 폴더는 **그 판의 앱 코드로 실제로 저장한 합성 조사**다(실제 유적 자료 없음). `ka_save_open_tests` 의 `oldVersionSurveysStillOpen` 이 빌드할 때마다 모두 열어 본다.

## 이 시험이 보는 것

1. 조사를 연다. 조사구역 도형 수, 도면 수, `manifest.ini` 의 레이어가 모두 살아 있다.
   - `external` 레이어는 표본을 만든 PC의 조사 폴더 밖(AppData 등)에 있던 자료다. 여기서는 없을 수 있다. 없으면 「원본 파일을 못 찾은 레이어」 알림에 나와야 한다.
2. 새 판으로 저장한다.
3. 다시 열어도 1과 같다.

이 시험이 깨지면 그 수정은 포터블을 새 판으로 바꿨을 때 예전 작업을 못 열게 만든 것이다. 표본을 고치지 말고 앱을 고친다.

## 표본 파일은 저장소에 있어야 한다

`.gitignore` 는 `*.gpkg`·`*.qgz` 를 무시한다(현장 조사 자료가 실수로 올라가지 않게). 그래서 이 폴더는 `!tests/data/compat/**` 로 예외를 둔다. 여기에는 **합성 자료만** 둔다. 실제 조사 GPKG 는 넣지 않는다.

2026-09-22 표본의 `survey/호환표본.gpkg`(와 동반 `.qgz`)는 예외가 생기기 전에 무시돼 커밋되지 않았고, 새 클론·CI·다른 PC 에서는 시험이 첫 줄에서 실패했다. 원본은 어느 PC 에서도 찾지 못했다. 그래서 `oldVersionSurveysStillOpen` 은 이 판의 조사 파일이 없으면 **그 판의 저장 모양 그대로** 합성 조사를 다시 만든다(`writeLegacySurvey20260922`, 근거는 3ddca7a 의 `SurveyStorage.cpp`·`LayerOps.cpp`):

- 작업공간은 조사 GPKG 안(`qgis_projects`, `projectName=survey`)에 **절대 경로**로 들어 있고, 조사 폴더 경로(`ka_hgis/survey_dir`)는 적혀 있지 않다.
- 흡수한 메모리 레이어(`주변 500m`, `지적도 본번`)는 저장 뒤 지워진 세대 사본 `.ka-survey-gen-*/survey.gpkg` 를 가리킨다.
- 지적 레이어는 옛 「지적도」 묶음에, `국가지정유산` 은 참조 지도 › 지정유산 에 있고 그 PC 의 AppData 에 있던 자료라 따라오지 않는다(`external=`).
- 지형 음영은 이 폴더의 `survey/ka-hgis-reference-T/relief.png` 를 쓴다(없으면 같은 8×8 그림을 만든다).
- 만든 PC 폴더는 끝에 지워 옮겨 온 조사처럼 연다.

다시 만들 수 없는 판의 조사 파일이 없으면 시험은 이유를 적고 실패한다(조용히 통과하지 않는다). 원래 2026-09-22 파일을 찾으면 `survey/` 에 넣고 커밋한다. 그러면 시험은 그 파일을 그대로 연다.

## 표본을 더하는 법

1. 그 판의 커밋을 따로 체크아웃한다(`git worktree add --detach <폴더> <커밋>`).
2. 그 판의 `tests/test_save_open.cpp` 에 표본 저장 함수를 잠시 넣는다(커밋하지 않는다). 조사구역, 버퍼, 참조 레이어, 래스터, 도면을 넣고 두 번 저장하는 함수다. 2026-09-22 표본을 만든 함수는 이 폴더의 `2026-09-22` 표본과 같은 내용을 만든다.
3. `KA_COMPAT_OUT=<출력 폴더>` 를 주고 그 판의 `ka_save_open_tests compatFixture_writeSurvey` 를 돌린다.
4. 출력의 `survey` 폴더에서 `복구사본`, `*.bak.qgz` 를 빼고 `tests/data/compat/<판 날짜>/survey` 로 옮긴다. `manifest.ini` 도 옮기고, 조사 폴더 밖 자료의 레이어 이름을 `external=` 에 적는다.

## 표본으로 찾은 것 (2026-09-22 판)

- 조사구역에 도형을 더해 저장하면 `UNIQUE constraint failed: survey_area.fid` 로 실패했다. 그 판과 당시 최신 판 모두 그랬다.
- 예전 「지적도」 묶음을 최상위로 올리면서 `takeChild` 를 써서 지적도·지적 배경 레이어가 지워졌다.
