# 찾기에서 지번 검색

오른쪽 위 **찾기**에서 시·도를 누른 뒤 시·군·구를 선택하고 법정동·리와 번지를 입력합니다.

- 동 지역: `역삼동` / `123-4`
- 읍·면 지역: `고아읍 봉한리` / `산 12-3`
- 구가 있는 시: 필요하면 동 입력란에 `영통구 이의동`처럼 구까지 입력합니다.
- 동 입력란은 직접 수정할 수 있습니다. 행정동 이름과 법정동 이름이 다르면 법정동을 입력하세요.
- 번지 없이 찾으면 기존 지역 검색을 사용합니다.

번지가 있으면 VWorld 지번 주소 검색을 사용하고 지역명·산 여부·본번·부번을 비교합니다. 서로 다른 필지 후보가 여럿이거나 전체 결과를 확인하지 못하면 자동 이동하지 않고 주소를 구체적으로 입력하도록 안내합니다. 서버 오류나 일치하지 않는 결과를 일반 장소 검색으로 대체하지 않습니다.

정확한 결과를 찾으면 지도에 위치 표식을 표시합니다. 앱에서 내려받아 열어 둔 지적도에 같은 필지 고유번호(PNU)가 있으면 해당 필지를 선택하여 경계를 강조하고 필지 범위로 이동합니다. 숨겨진 해당 지적도는 상위 그룹과 함께 켜집니다. 원본 도형과 속성은 수정하지 않습니다. 지역 밖 필지는 주소 검색의 위치 표식으로 표시됩니다.

VWorld API 키와 인터넷 연결이 필요합니다. 기존 앱의 키 설정을 사용합니다. 최근 분할·합병, 행정구역 변경, 검색기관 자료의 미반영 때문에 실제 지번이 검색되지 않을 수 있습니다. 주소 일치 확인은 지적 경계의 측량 정확도를 보증하는 기능이 아닙니다.

구현 요청 형식: VWorld Search API 2.0, `type=ADDRESS`, `category=PARCEL`, `crs=EPSG:4326`. [공식 문서](https://www.vworld.kr/dev/v4dv_search2_s001.do).
