# 현재 지도를 GeoTIFF로 저장

1. **지도** 탭에서 필요한 레이어를 켜고 저장할 범위를 화면에 맞춥니다.
2. 상단 **내보내기 → GeoTIFF 저장**을 누릅니다.
3. 저장 위치와 파일 이름을 정하면 `.tif` 한 개로 저장됩니다.

추가 좌표계·해상도 설정은 없습니다. 현재 지도 좌표계, 표시 범위, 회전, 레이어 순서·스타일·투명도를 사용합니다. 화면의 논리 픽셀 크기로 지도를 다시 렌더링하며, GeoTIFF 내부에 좌표계와 픽셀 위치 정보를 기록합니다. 좌표 변환은 기존 QGIS 지도 렌더러가 수행합니다.

결과는 RGB 8비트의 일반 TIFF입니다. 측량기의 배경 영상용이며, 고도 수치가 들어 있는 DEM을 만드는 기능은 아닙니다. SMARTTOPO C에서 실제 파일을 불러오는 검증은 별도로 필요합니다.

저장 중 취소할 수 있습니다. 취소·저장 실패 때 기존 출력 파일을 유지하며, 현재 조사에 열린 원본 영상과 같은 파일로 덮어쓰는 것은 막습니다. 원본 조사·레이어는 수정하지 않습니다.

완료하면 하단 상태표시줄에 저장 위치와 좌표계가 표시됩니다. 지도에 레이어가 없거나 일부 레이어를 렌더링하지 못하면 저장하지 않고 안내합니다.
