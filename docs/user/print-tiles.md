# 도면 인쇄와 여러 장 나눠 찍기

**도면 만들기** 화면의 **인쇄**(또는 Ctrl+P)로 찍는다. 인쇄물은 **PDF 내보내기**와 같은 도면을 쓴다. 유적 번호·범례·격자까지 PDF와 똑같다.

## 두 가지 방법

- **용지 한 장에 맞춰 인쇄**: 도면 전체를 A4나 A3 한 장에 비율대로 줄이거나 키워 가운데에 찍는다.
- **여러 장으로 나눠 크게 인쇄**: 큰 도면을 A4·A3 여러 장으로 나눠 찍고, 붙여서 큰 도면을 만든다. 예를 들어 A0(841×1189 mm) 도면은 A3 9장(가로 3 × 세로 3)이 된다.

## 여러 장 나눠 찍기에서 고르는 것

| 칸 | 뜻 |
| --- | --- |
| 완성 크기 | **도면 크기 그대로**면 도면 축척이 그대로다. **A0·A1·A2·A3 크기로 맞춤**은 도면을 그 크기에 맞게 키우거나 줄인다. |
| 용지 | 한 장씩 찍을 용지(A4·A3). 세로·가로는 장수가 적은 쪽으로 저절로 고른다. |
| 겹침 | 이웃 장과 같은 그림이 겹치는 폭(기본 10 mm). 붙일 때 맞추기 쉽다. |
| 자르는 점선과 장 번호 | 오른쪽·아래에 자를 점선, 모서리에 시작선 표시, 아래 띠에 「2행 3열 (6/9장)」 같은 번호를 찍는다. |

창 아래에 몇 장이 나오는지와 붙였을 때 크기가 보이고, 미리보기에 나눈 칸과 번호가 그려진다.

- 장수는 프린터가 찍지 못하는 가장자리 폭에 따라 달라질 수 있다. 가장자리는 5 mm와 프린터가 알려 준 값 중 큰 쪽을 쓴다.
- **도면을 키우거나 줄이면** 창에 경고가 나온다. **숫자로 적은 축척**(예: 1:5,000)은 실제와 달라진다. **막대 축척**은 도면과 같이 커지고 작아지므로 그대로 맞다.

## 붙이는 법

1. 번호 순서(1행 1열부터)대로 늘어놓는다.
2. 각 장의 오른쪽·아래 **점선**을 따라 자른다.
3. 자른 가장자리를 옆 장 그림의 **시작선**(모서리의 짧은 선)에 맞춰 겹쳐 붙인다.

## 프린터가 없을 때

**나눈 장을 PDF로 저장…**을 누르면 한 장이 PDF 한 쪽인 파일이 된다. 다른 PC나 출력소에서 **실제 크기(100%)**로 찍으면 된다.
