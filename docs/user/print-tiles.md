# 도면 인쇄와 여러 장 나눠 찍기

리본의 **인쇄**, **도면 만들기** 화면의 **인쇄**, 또는 **Ctrl+P**로 찍는다. 리본이나 Ctrl+P로 부르면 도면 만들기를 먼저 열고 곧바로 인쇄 창을 띄운다. 인쇄물은 **PDF 내보내기**와 같은 도면을 쓰므로 유적 번호·범례·격자까지 PDF와 똑같다.

## 두 가지 방법

인쇄 창은 도면이 용지 한 장에 실제 크기로 들어가면 **한 장에 인쇄**로, 넘치면 **여러 장으로 나눠 크게 인쇄**로 열린다.

- **한 장에 인쇄**
  - 도면이 용지에 들어가면 **실제 크기(100%)**로 용지 한가운데에 찍는다. 축척이 그대로다.
  - 넘칠 때만 용지에 맞춰 줄이고, 몇 %로 줄였는지와 **종이 위 실제 축척**을 창에 알린다.
- **여러 장으로 나눠 크게 인쇄**: 큰 도면을 A4·A3 여러 장으로 나눠 찍고, 붙여서 큰 도면을 만든다. 예를 들어 A0(841×1189 mm) 도면은 A3 9장(가로 3 × 세로 3)이 된다.

## 여러 장 나눠 찍기에서 고르는 것

| 칸 | 뜻 |
| --- | --- |
| 붙였을 때 크기 | 아래 세 가지 가운데 고른다. |
| 용지 | 한 장씩 찍을 용지(A4·A3). 세로·가로는 장수가 적은 쪽으로 저절로 고른다. |
| 겹침 | 이웃 장과 같은 그림이 겹치는 폭(기본 10 mm). 붙일 때 맞추기 쉽다. |
| 자르는 점선·장 번호·5 cm 확인선 | 오른쪽·아래에 자를 점선을, 모서리에 시작선을 찍는다. 아래 띠에는 전체에서 이 장의 자리를 까맣게 칠한 작은 칸 지도, 「5번 장 (2행 2열) / 전체 9장 · 종이 위 축척 1:2,500」 같은 글, **5 cm 확인선**을 찍는다. |
| 붙이는 순서 안내 한 장 | 맨 앞에 도면 전체와 나눈 칸·번호, 붙이는 순서를 담은 안내 장을 한 장 더 찍는다. |

**붙였을 때 크기**의 세 가지는 이렇다.

- **도면 크기 그대로 · 1:5,000 · A3**: 도면 축척 그대로 찍는다.
- **1:2,500으로 키우기 · 2배 · 약 A1**: 딱 떨어지는 축척으로 키운다. A0보다 커지지 않는 것만 보인다.
- **A0에 맞춤 · 종이 위 약 1:1,766**: 용지 크기에 맞춰 키우거나 줄인다. 축척은 딱 떨어지지 않는다.

창 아래에는 다음이 보인다.

- 몇 장이 나오는지, 어떻게 놓이는지, 붙였을 때 크기, 종이 위 축척.
- 미리보기: 나눈 칸과 번호. 인쇄 단추에도 쪽수가 적힌다(예: 「인쇄 · 9장 + 안내 1장」).

장수와 축척에 대해 알아 둘 것:

- 장수는 프린터가 찍지 못하는 가장자리 폭에 따라 달라질 수 있다. 가장자리는 5 mm와 프린터가 알려 준 값 중 큰 쪽을 쓴다.
- 도면을 키우거나 줄이면 도면에 적힌 **숫자 축척 글씨**(예: 1:5,000)는 그대로 찍혀 실제와 달라진다. 그래서 창과 각 장의 번호 띠에 **종이 위 실제 축척**을 적는다. **막대 축척**은 도면과 같이 커지고 작아지므로 그대로 맞다.

## 잘못 나온 장만 다시 찍기

종이가 걸리거나 한 장이 잘못 나왔을 때 쓴다.

1. 미리보기에서 **다시 찍지 않을 장을 누른다.** 누른 장은 회색으로 「3 뺌」처럼 표시되고, 다시 누르면 돌아온다.
2. 창에 「이번에는 2장만 찍습니다」처럼 나오면 그대로 인쇄한다. 이때는 안내 장을 다시 찍지 않는다.
3. **모두 다시 넣기**를 누르면 처음처럼 모든 장을 찍는다.

## 붙이는 법

맨 앞 안내 장에도 같은 순서가 적혀 있다.

1. 번호 순서대로 늘어놓는다. 1번이 왼쪽 위다.
2. 각 장의 오른쪽·아래 **점선**을 따라 자른다.
3. 자른 가장자리를 옆 장 그림의 **시작선**(모서리의 짧은 선)에 맞춰 겹쳐 붙인다.
4. 각 장 아래 **확인선**을 자로 잰다. 5 cm면 프린터가 줄이거나 키우지 않고 맞게 찍은 것이다.

## 프린터가 없을 때

1. **나눈 장을 PDF로 저장…**을 누르면 한 장이 PDF 한 쪽인 파일이 된다.
2. 다른 PC나 출력소에서 꼭 **실제 크기(100%)**로 찍는다. 「용지에 맞춤」으로 찍으면 축척이 틀어진다.

오래 걸리는 인쇄나 저장은 진행 창의 **멈추기**로 그만둘 수 있다. 반쯤 쓴 PDF는 남기지 않는다.

프린터·용지·겹침·표시 설정은 인쇄나 저장에 성공하면 기억했다가 다음에 그대로 쓴다.
