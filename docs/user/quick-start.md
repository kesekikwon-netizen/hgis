# Strata(고고학 전용 HGIS) 현장 첫 조사 안내

처음 쓰는 사람이 조사 하나를 **새 조사 → 배경 → 그리기 → 저장 → 도면 → 검수·제출**까지 끝내는 순서다. 화면 이름은 지금 앱의 리본 글자 그대로 적었다. 자세한 기능별 설명은 같은 폴더의 다른 문서(지적·주변유적·조판·인쇄)를 본다.

## 0. 실행

- 포터블은 폴더를 **통째로** USB·PC 에 두고 `ka-hgis.exe` 를 더블클릭한다. EXE 만 옮기면 좌표계를 못 읽어 지도가 뜨지 않는다.
- 다른 PC 에서 처음 열 때 Windows 가 「PC 보호」 창을 띄우면 **추가 정보 → 실행**을 누른다(서명되지 않은 앱 안내).
- 시작 안내 카드가 3초쯤 보인 뒤 **홈**이 열린다. 앱은 켤 때 조사·배경지도를 스스로 열지 않는다. 홈에서 고른다.

## 1. 새 조사

1. 홈 또는 리본 **조사 › 새 조사**(Ctrl+N).
2. **조사명**을 적고 **작업 좌표계**를 고른다: **5186 중부원점** 또는 **5187 동부원점**(기본 5187). 조사 지역에 맞는 쪽을 창의 안내대로 고른다.
3. **다음** → 저장 폴더를 고른다. 폴더 안에 `조사명.gpkg`(조사 파일)가 생긴다.

레이어 목록은 비어 있는 것이 정상이다. 조사구역·유구 레이어는 처음 그리거나 가져올 때 **조사 데이터** 묶음에 생긴다. 이미 있는 조사는 **조사 › 열기**(Ctrl+O)나 홈의 **최근 조사**로 연다.

## 2. 배경 지도·자료

- VWorld 위성·지적 그림은 **VWorld API 키**가 있어야 보인다. 키는 리본 **기타 › 더보기 › API 키 입력**에 한 번 넣는다.
- **배경 지도** 묶음: 지형, DEM, 등고선, 토양, 고지형, 지질, 수계, 옛 지도. 다시 누르면 숨긴다.
- **자료 받기** 묶음: **지적**(조사구역 주변 5km 지적도), **수치지형**(국토지리정보원 도엽), **유산**(주변유적, 선택한 시·군). 계정이 필요한 것은 **더보기**의 아이디·비밀번호 항목에 넣는다.
- 배경·참조 자료는 **참조 지도**(지적은 목록 맨 위 단계)에 놓이고 조사 데이터와 섞이지 않는다. 위성 같은 그림에는 자석이 붙지 않는다.
- 주소나 지번으로 이동: 위쪽 찾기 칸(Ctrl+F). 지도만 옮기고 핀은 남기지 않는다.

## 3. 그리기

1. 리본 **기록 › 그리기**(Ctrl+D) → 아래 줄에서 **조사구역 그리기**, **유구 그리기**, **유구 선**, **유물위치표시** 중 하나를 고른다.
2. 지도에서 점을 차례로 찍는다. **오른쪽 클릭·Enter·더블클릭**으로 끝내고, **Esc** 로 지금 그리던 것을 버린다. 방금 찍은 점만 지우려면 Backspace 또는 Ctrl+Z.
3. **자석**을 켜면 조사 도형·지적 선에 붙는다. **쉽게그리기**는 모서리에 저절로 붙는다.
4. 그리는 동안에는 속성 창이 뜨지 않는다. 다 그린 뒤 필요한 경우에만 이름·번호 창이 나온다.
5. 이미 그린 도형을 고치거나 지우려면 **도형선택**(Ctrl+1)으로 고른 뒤 꼭짓점을 끌거나 Delete.

## 4. 저장

- **저장**(Ctrl+S). 저장하지 않은 변경이 있으면 창 제목 끝에 ` *` 가 붙는다. 앱은 스스로 저장하지 않는다. 닫을 때 저장 여부를 묻는다.
- 조사 파일(`.gpkg`)과 같은 폴더의 자료(가져온자료·주변유적 등)는 **폴더째** 옮기면 다른 PC 에서도 그대로 열린다.

## 5. 도면

- **내보내기 › 도면**(Ctrl+L)으로 조판 창을 연다. 기본 용지는 지도 틀만 있다. 제목·범례·축척 등은 필요한 것만 더한다.
- **인쇄**(Ctrl+P), **단면도**는 같은 묶음에 있다.

## 6. 검수·제출

1. **내보내기 › 검수·제출**(Ctrl+E) → 검수 결과를 본다.
2. **error**(빨강) 항목은 제출을 막는다. 항목의 안내대로 고친 뒤 다시 누른다. **warn** 은 확인만 하면 된다.
3. 통과하면 빈 폴더를 고른다. **EPSG:5179 SHP** + **조사도면.pdf** + **MANIFEST** 가 만들어진다. 작업 좌표계(5186/5187)와 상관없이 제출 파일은 5179 로 변환된다.

| Ctrl+D | 그리기 |

| Ctrl+F | 주소·지번 찾기 |

| Ctrl+P | 인쇄 |

| F11 | 전체 화면 |

## 용어

| 용어 | 뜻 |
| --- | --- |
| 조사 파일 | 조사 하나를 담은 `.gpkg`. 도형과 작업 화면이 함께 들어 있다 |
| 조사 데이터 | 직접 그린 조사구역·유구·단면선·기준점·유물 레이어 |
| 참조 지도 | 위성·지형·토양·주변유적처럼 보고 맞추는 자료. 조사 데이터가 아니다 |
| 조사구역 | 조사 범위 면(survey_area) |
| 유구 면 / 유구 선 | 유구 윤곽(feature_poly) / 선형 유구·경계(feature_line) |
| 기준점 | GPS·측량 기준점(control_points). 제출에는 2점 이상과 측지기준계·타원체·투영이 필요하다 |
| 작업 좌표계 | 그리고 저장하는 좌표계. 5186(중부원점) 또는 5187(동부원점) |
| 제출 좌표계 | 제출 SHP 의 좌표계 EPSG:5179. 변환은 제출 때만 한다 |
| 정합 | 스캔 도면·영상을 지도 좌표에 맞추는 일 |
| 자석 | 그릴 때 가까운 꼭짓점·선에 붙이기 |
| 검수 error / warn | error 는 제출을 막고, warn 은 확인만 한다 |
| MANIFEST | 제출 폴더 파일들의 SHA-256 목록. 받은 쪽이 파일이 온전한지 대조한다 |

## 문제 해결

| 증상 | 할 일 |
| --- | --- |
| 위성·지적이 하얗다 | 인터넷 연결을 확인하고 **더보기 › API 키 입력**에 유효한 VWorld 키가 있는지 본다. 키가 없으면 VWorld 배경은 올리지 않는다 |
| 받기(지적·수치지형·주변유적)가 실패한다 | 받기 창의 **상세 보기**에서 단계를 확인하고 다시 누른다. 계정 자료는 **더보기**의 아이디·비밀번호를 확인한다. 회사망·방화벽이 막는 경우가 있다 |
| 도형이 지도와 어긋난다 | 아래 상태줄의 **작업 5186/5187**이 조사 지역과 맞는지 본다. 가져온 자료의 좌표계가 틀렸으면 원본의 .prj 를 확인한다. 좌표계 이름만 바꾸는 조작은 도형을 옮기지 않는다 |
| 열었더니 「원본 파일을 못 찾은 레이어」가 나온다 | 조사 폴더 밖(다른 드라이브·AppData)에 있던 자료다. 원본을 조사 폴더로 옮기고 다시 연다. 조사 폴더는 통째로 옮긴다 |
| 제출이 막힌다 | 검수 결과의 error 항목마다 적힌 고칠 방법을 따른다. 고치고 저장한 뒤 다시 검수·제출 |
| 다른 PC 에서 계정을 다시 묻는다 | 계정·키는 PC 마다 앱에서 넣는다. 개인용 포터블만 예외로 계정을 함께 담을 수 있다([portable-desktop.md](../portable-desktop.md)) |
