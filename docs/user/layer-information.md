# 도면과 글자 켜기·끄기

지도 탭과 레이아웃 탭의 **왼쪽 레이어 목록**에서 바로 조작합니다.

| 위치 | 하는 일 |
|---|---|
| **도면 · 레이어** 열의 체크 | 그 도면의 도형과 글자를 모두 켜고 끕니다. |
| **글자** 열의 체크 | 도형은 남기고 지번·높이·유적명·번호 등의 글자만 켜고 끕니다. |
| 목록 아래 **표시 설정** | 선택한 도면의 글자 표시, 지원하는 내용·면적·글자 크기를 바꿉니다. |

- 여러 도면이 든 그룹의 **글자** 체크로 하위 글자를 함께 바꿉니다. 일부만 켜졌으면 중간 체크로 표시됩니다. 중간 상태를 누르면 모두 켜고, 모두 켜진 상태를 누르면 모두 끕니다.
- 도면 또는 상위 그룹을 숨기면 글자 체크도 흐리게 표시됩니다. 기존 글자 설정을 기억했다가 도면을 다시 켜면 복원합니다.
- 체크를 선택한 뒤 **스페이스 키**로도 켜고 끌 수 있습니다. 오른쪽 글자 열에서는 글자만 바뀝니다.
- 긴 레이어 이름은 아래 표시 설정에서 확인할 수 있습니다. 목록과 지도 사이 경계선을 끌면 목록 폭을 바꿀 수 있습니다.
- **열 너비 조절:** 목록 맨 위의 **도면 · 레이어 | 글자** 사이 세로 경계선을 좌우로 끕니다. 지도와 레이아웃 모두 지원하며, 창 크기를 바꿔도 현재 목록에서 조절한 너비를 유지합니다. 창을 아주 좁히면 두 열이 보이도록 너비를 제한합니다.

## 더 촘촘한 목록과 색 구분

- 지도·레이아웃의 레이어 목록 글자는 기존 13px에서 10px로 약 20% 작아졌습니다. 지도 안의 지명·번호·도면 글자 크기는 바뀌지 않습니다.
- 그룹은 **진한 파랑·굵은 글씨**, 일반 레이어는 진한 회색, 꺼진 레이어는 옅은 회색·기울임꼴로 구분합니다. 상위 그룹을 끄면 하위 레이어도 숨김 상태의 글자로 바뀝니다.
- 레이어 고유색은 이름 앞의 선·도형 표시로 확인합니다. 행 배경은 흰색과 옅은 색을 번갈아 사용합니다.
- 기본 행 높이는 34px에서 22px로 줄어, 같은 높이에 약 50% 더 많은 행이 보입니다. 체크와 열 너비 끌기 기능은 그대로 사용할 수 있습니다.

## 자료에 따라 다른 설정

- **지적도:** 지번을 켜고 끕니다. 확대해야 표시되는 경우 아래에 축척 안내가 나옵니다. 기존 1:10,000 표시 기준과 선 색은 유지됩니다.
- **수치지형도:** 등고선·표고점의 높이, 지명 등 해당 레이어에 설정된 글자만 바뀝니다. 기존 높이 표시 규칙을 유지합니다.
- **주변유적:** 지도에서는 유적명, 조판에서는 번호입니다. 조판 번호를 끄면 연결된 번호 범례 항목도 빠지고, 다시 켜면 페이지에 보이는 유적에 맞춰 자료 분류별 연번으로 복원합니다. 일반 지도의 유적명 설정은 그대로입니다.
- **조사구역 등 일반 도형:** 지원하는 경우 표시할 내용과 면적을 선택할 수 있습니다. 지번·높이·지질기호처럼 전용 규칙이 있는 도면에는 불필요한 내용 선택을 표시하지 않습니다.
- **직접 가져온 자료:** 어떤 글자를 쓸지 알 수 없으면 `표시할 내용을 먼저 선택해 주세요`가 나옵니다. 아래 **내용**에서 항목을 선택합니다. 내부 코드를 임의로 표시하지 않습니다.
- **영상·위성·DEM:** 별도로 조작할 글자가 없으면 `—`로 표시합니다. 이미지에 이미 들어간 글자는 이 체크로 지울 수 없습니다. DEM 색상 범례는 조판에서 설정합니다.

글자만 켜고 끌 때 원래 서체·색·위치·축척 제한을 유지합니다. 글자가 서로 겹치거나 해당 축척에서 숨겨지는 경우 체크가 켜져 있어도 모든 글자가 나오지는 않습니다.

설정을 보관하려면 **조사 저장**을 누릅니다. 다음에 그 조사를 열면 저장된 설정을 사용합니다.
