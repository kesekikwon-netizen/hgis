# 글로시 아이콘

앱의 기능 버튼에 둥근 색상 타일, 위쪽 광택, 밝은 기능 그림을 적용했습니다. 기존 기능과 버튼 이름은 같습니다. 조사파일은 파랑, 기록 도구는 황토색, 지도는 녹색, 좌표 정합은 보라색 등 기존 기능별 색 구분을 유지합니다.

- 켜진 도구는 체크 표시, 선택된 아이콘은 테두리로 구분합니다.
- 비활성 아이콘은 회색으로 표시합니다.
- 고해상도 화면을 위해 기능 아이콘을 64·128픽셀로 렌더링합니다.
- 앱 창과 Windows 실행 파일·바탕화면 바로가기는 금색 발굴용 흙손 아이콘을 사용합니다.

바탕화면의 **고고학 전용 HGIS** 바로가기는 현재 개발 Release를 엽니다. `scripts/start-ka-hgis.vbs` → `launch.ps1` → `build/Release/ka-hgis.exe` 경로입니다. 앱 내부 변경은 다음 실행부터 적용됩니다.

## 개발용 자산

- 투명 PNG 마스터: `data/theme/ka-hgis-app.png`
- Qt 내장 리소스: `data/theme/icons.qrc`
- Windows ICO: `data/theme/ka-hgis.ico`, `src/app/ka-hgis.ico`
- 변환/바로가기 도구: `scripts/update-app-icon.ps1` (`-UpdateDesktopShortcut`은 명시적인 바로가기 갱신 옵션)

ICO에는 16·20·24·32·48·64·128·256픽셀이 들어 있습니다. PNG 마스터를 바꿀 때는 Qt 리소스도 새로 빌드하고, `theme_qss`의 내장 이미지 해시 검사를 통과해야 합니다. 파일 복사가 원래 수정 시간을 보존하면 이전 리소스가 남을 수 있으므로 새 마스터 반영 시 QRC 근거도 갱신합니다.

마스터는 사용자가 제공한 두 번째 이미지를 바탕으로 이미지 생성 도구에서 파생한 자산입니다. 원본 참고 이미지 자체나 최초 생성의 불투명 격자 배경 이미지를 실행 파일에 사용하지 않습니다. [생성·검증 기록](../../build/qa/glossy-icons-20260916/asset-provenance.md).
