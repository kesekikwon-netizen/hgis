# v2 시작 화면과 다운로드 창

## 시작 화면

앱을 실행하면 **Strata · 필드고고학 GIS** 시작 안내 카드가 먼저 나옵니다. 모서리가 둥근(반지름 16) 파란 카드이고, 투명한 여백 위에 부드러운 그림자와 위쪽의 옅은 광택이 있습니다.

- **동국문화재연구원 · 만든이 권영인**을 표시합니다.
- 준비하는 동안 카드 아래에서 점 다섯 개가 흐르며 「앱을 준비하고 있습니다」가 보입니다. 준비가 끝나면 5초 뒤 홈 화면이 열립니다(그동안 저작권·기술 안내를 읽을 수 있습니다). Windows 에서 애니메이션 효과를 끄면 점도 움직이지 않습니다. PC의 초기 준비 시간은 별도로 걸릴 수 있습니다.
- 화면을 클릭해도 안내가 바로 사라지지 않습니다.
- 저작권·참조 정보는 앱의 **정보** 메뉴에서도 다시 확인할 수 있습니다.
- 실행 시 조사를 자동으로 불러오지 않습니다. 홈에서 조사 열기나 새 조사를 선택하세요.

## 다운로드 창

수치지형도·지적도·주변유적 다운로드는 같은 파란 제목 카드와 흰 상태 카드, 진행 막대, 하단 취소 버튼을 사용합니다.

- **제목 카드:** 받는 자료와 제공처를 확인합니다.
- **상태 카드:** 현재 단계·안내·실제 진행 상태를 확인합니다. 수신량을 알 수 없는 단계에서는 움직이는 막대나 ‘진행률 확인 중’을 표시합니다.
- **상세 보기:** 로그인·인증이나 처리 내용을 확인할 때 펼칩니다. 수치지형도의 전체 단계 목록·도엽 및 파일별 수신 정보·공식 사이트도 이 안에 있습니다. 펼친 상태에서도 현재 단계와 진행 막대는 위에 계속 표시됩니다.
- **취소:** 진행 중인 작업의 기존 취소 처리로 연결됩니다. 다시 받으려면 앱의 다운로드 기능을 실행하세요.

지적도는 조사구역 경계에서 주변 5km, 주변유적은 선택한 시·군, 수치지형도는 해당 기능에서 선택한 도엽 범위를 사용합니다. 화면 디자인을 바꿔도 자료 범위와 좌표계 처리 방식은 같습니다.

세 다운로드 창은 비모달 창으로 열려 지도 작업을 계속할 수 있습니다. 수치지형도에도 기본 680×330 논리 픽셀의 공통 구성을 적용합니다. 화면 배율·표시 내용에 따라 크기를 조정하며, 상세 내용은 창 안에서 스크롤할 수 있습니다.
