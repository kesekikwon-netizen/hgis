# 조판의 주변유적 번호와 범례

조판에서는 주변유적의 긴 이름 대신 **레이어 색으로 채운 원 안의 번호**를 표시한다. 범례에는 **같은 색 원·번호와 유적명**이 함께 나온다. 일반 지도 화면의 유적명과 원본 자료는 바꾸지 않는다.

- 지정유산·현상변경허용기준·매장유산유존지역·문화유적분포지도·지표조사구역·발굴조사구역은 **각 분류에서 1번부터** 시작한다.
- 같은 레이어에서 같은 유적명으로 묶인 도형은 같은 번호를 쓴다. 다른 레이어의 같은 이름은 별도 항목으로 구별한다.
- 조판에 켠 레이어와 도면 범위 안의 유적만 번호를 매긴다. 숨긴 분류 심볼과 범위 밖 유적은 제외한다.
- 도면을 이동하거나 축척·레이어 표시를 바꾸면 번호와 범례가 함께 갱신된다. 따라서 범위가 바뀌면 번호가 달라질 수 있다.
- PDF 저장 직전에도 갱신한다. **항목 이동**으로 범례를 선택하고 오른쪽 변이나 모서리를 가로로 넓히면 여러 열로 자동 배치된다. 폭을 줄이면 열 수가 줄어든다. 높이는 내용에 맞춰 조절되며, 긴 유적명은 줄바꿈된다. 범례 위치와 색 원·번호·이름은 유지된다.
- 레이아웃 탭으로 돌아올 때 자료·도면 범위·축척이 같으면 기존 번호와 범례를 재사용한다. 자료나 색을 바꾼 뒤 돌아오면 변경 내용을 반영한다.
- 레이아웃 탭에서는 창 하단 축척과 **도면 정보**가 같은 도면 축척을 표시한다. 어느 쪽에서 바꿔도 도면에 적용된다. 지도 탭으로 돌아가면 일반 지도의 축척을 표시한다.
- 항목을 끌거나 크기를 조절하는 동안 무거운 번호·범례 계산을 보류하고, 놓으면 최종 상태를 반영한다. 범례 제목·글꼴 변경은 번호를 다시 만들지 않는다.
- 가까운 번호는 주변 빈 공간으로 살짝 옮겨 두고 가는 연결선으로 유적 위치를 표시한다. 도면 안에서 번호 원은 겹치지 않는다. 숫자뿐 아니라 색 원의 크기도 간격 계산에 포함한다.
- 범례에는 **지도에 실제로 그린 번호**만 나온다. 화면의 숫자와 범례의 숫자는 같다. 종이 위 지도 범위의 유적을 후보로 잡고, 겹치지 않게 놓인 것만 자료 분류별 1·2·3…으로 다시 매긴다. 공간이 부족해 숨긴 번호는 지도와 범례에서 함께 뺀다. 24 다음에 30처럼 빈 번호는 남기지 않는다. 축척을 1:5000에서 1:25000으로 넓히면 범위 후보가 늘어나고, 겹치지 않게 놓을 수 있는 만큼 범례도 늘어난다. 같은 유적의 여러 도형은 번호를 공유하며 범례에는 한 번만 넣는다.
- 축척·범위·자료·용지나 지도 항목 위치가 바뀌면 범위 안 유적을 다시 세고 번호를 다시 매긴다.
- PDF 저장 직전에도 같은 화면=범례 규칙을 반영한다. 조판 PDF 버튼과 제출용 PDF 모두 같은 규칙을 쓴다.

기본 분류색은 **지정유산 보라 / 현상변경허용기준 주황 / 매장유산유존지역 파랑 / 문화유적분포지도 초록 / 지표조사구역 금황 / 발굴조사구역 진분홍**이다. 기존 기본 청록·갈색도 조판 복제본에서는 새 색으로 표시하며, 사용자 지정 색과 원본 스타일은 유지한다.

현재 인트라넷에서 적재하는 이름별 분류 스타일과 단일 심볼 스타일을 지원한다. 원본 도형·속성·스타일을 바꾸지 않고 조판 복제본에만 번호와 새 기본색을 적용한다. 실제 이름 속성이 없는 자료는 범례에 `무명`으로 표시한다.

축척자·축척 글자·좌표계·방위표의 이동 및 크기는 [조판 장식 사용법](layout-decorations.md)을 따른다.
