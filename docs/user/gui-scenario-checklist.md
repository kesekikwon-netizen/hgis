# GUI 시나리오 기록 서식

릴리스마다 이 서식으로 **기록 1부**를 만든다. 에이전트가 대신 클릭해 채우지 않는다. 사용자가 화면을 보고 **화면 · 조작 · 관측**을 적는다.

- 바탕화면 **고고학 전용 HGIS** 또는 `.\scripts\run-ka-hgis.ps1`로 연 앱만 사용한다.
- 원본 현장 GPKG(`제주 광령리.gpkg` 등)는 쓰지 않는다. 새 조사 또는 사본만.
- 시작 시 조사·배경이 자동으로 열리면 안 된다. 사용자가 **조사 열기** / **새 조사**를 고른 뒤만 지도가 열린다.

## 기록 칸

| 칸 | 누가 | 무엇을 |
| --- | --- | --- |
| 화면 | 사용자 | 창 제목, 해상도·배율(예: 1920×1080 / 100%), 보이는 리본·지도·목록 |
| 조작 | 사용자 | 누른 단추·단축키·순서. 마우스면 어디를 눌렀는지 |
| 관측 | 사용자 | 됨 / 안 됨 / 부분. 안 되면 눈에 보인 글·빈 지도·오류 창 |

판정은 **됨** 또는 **안 됨**만 쓴다. “됐을 것”은 안 됨으로 둔다.

## 시나리오 (핵심)

| ID | 의도 | 조작 힌트 |
| --- | --- | --- |
| S1 | 시작은 홈만 | 앱을 켠다. 조사·위성·지적·최근 항목이 자동으로 열리지 않는지 |
| S2 | 새 조사 | 리본 **새 조사**(또는 Ctrl+N). 이름·5186/5187·폴더. 범례에 빈 도메인 레이어가 자동으로 안 생기는지 |
| S3 | 저장 | 도형을 그린 뒤 **저장**(Ctrl+S). 다시 열면 같은 도형이 있는지 |
| S4 | Tab/Enter | 리본에서 Tab으로 **새 조사**→**저장**까지 가고 Enter로 실행되는지 |
| S5 | 작은 창 목록 | 1366×768/100% 또는 1920×1080/200%에서 레이어 목록이 5행 이상인지. 부족하면 파일함·표시 설정이 접히는지 |
| S6 | 도면·제출 | **도면 만들기**(Ctrl+L), **5179 내보내기**(Ctrl+E). SHP는 5179인지 |
