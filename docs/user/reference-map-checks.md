# 참조 지도와 조판 범례

- **참조 지도** 그룹을 끄면 하위 도형·번호·범례가 함께 숨겨진다. 하위 항목의 개별 체크는 보존되어 그룹을 다시 켜면 원래 선택대로 돌아온다.
- 배경 지도 버튼으로 특정 지도를 명시적으로 켜면 그 지도의 상위 그룹도 켜진다.
- DEM 범례는 생성하거나 갱신할 때 선택한 폭을 유지한다. 이전 오류로 폭이 1mm가 된 범례는 다시 갱신하면 읽을 수 있는 폭으로 복구한다.
- 지질도·토양도와 주변유적 번호를 함께 표시해도 범례에는 도면 범위에 표시되는 분류가 나온다. 도면 범위가 바뀌면 내용과 높이를 다시 맞춘다. 가로로 넓히면 여러 열로 배치된다.
- PDF 저장 전에 범례 필터와 높이를 확정한다.
- 새로 받는 지질도는 응답 좌표계를 확인하고 실제 좌표변환을 거쳐 저장한다. 알 수 없는 좌표계나 변환 실패가 있으면 기존 지도를 유지하며 오류를 알린다.

이미 내려받은 파일이나 조사 원본의 좌표계를 임의로 바꾸지 않는다. 현재 화면에서 위치가 어긋나는 경우, 해당 레이어가 포함된 조사본을 다른 이름으로 저장하면 원본을 보존하면서 상태를 대조할 수 있다.
