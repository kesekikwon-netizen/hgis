# 조사 주변 지적도 받기

1. 조사를 열고 조사구역을 그리거나 기존 조사구역을 확인합니다.
2. 위쪽 **배경 지도 → 지적도**를 누릅니다.
3. 앱이 조사구역 경계에서 **주변 5km**와 겹치는 시·군·구를 찾고 VWorld 지적도를 받아 정리합니다. 진행 창에서 단계와 진행률을 확인하거나 취소할 수 있습니다. 받는 동안 지도 작업을 계속할 수 있습니다.
4. 완료하면 **참조 지도**에 `지적도 · 조사 주변 5km`가 생깁니다. **조사 저장**으로 지도 구성과 표시 설정을 보관합니다.

## 표시 설정

지적도 버튼 옆 메뉴의 **선 색·지번 표시**에서 색을 바꾸거나 지번을 켜고 끕니다.

- 기본값: 검정 경계선 **0.2mm**, 면 채움 없음.
- 지번을 켠 상태에서도 **1:10,000보다 확대할 때** 지번을 표시합니다. 넓은 범위의 수만 개 지번을 한꺼번에 배치하는 부담을 줄입니다.
- 축소해도 필지 경계선은 남습니다. 지번과 경계선 색 설정은 조사 저장 후 재열기와 조판에도 반영됩니다.
- 기존 VWorld 온라인 지적도의 글자와 중복되지 않도록 해당 온라인 지적도는 숨깁니다. 다른 조사·참조 자료는 유지합니다.

## 계정과 저장 위치

- 지적도 버튼 옆 **VWorld 계정 설정**에서 아이디·비밀번호를 저장하거나 수정합니다. 이 계정은 웹사이트 로그인용이며 **VWorld API 키**와 다릅니다.
- 5km 범위의 행정구역 판정은 기존 **더보기 → API 키 입력**에 넣은 VWorld 키를 사용합니다.
- 계정은 이 PC의 개인 설정 파일에 저장하며 소스 코드에 넣지 않습니다. 추가 인증이나 계정 제한이 발생하면 이유를 알리고 중단합니다.
- 조사 폴더의 `지적도/원본`에 받은 ZIP과 검증된 압축 해제 자료, `지적도/표시`에 범위를 추린 GeoPackage가 저장됩니다.
- 표시 파일은 경계와 겹치는 필지를 온전한 형상으로 유지하며 PNU와 지번만 보관합니다. 공간 인덱스로 현재 화면의 필지를 찾습니다. 원본 SHP를 수정하거나 경계에 인위적인 절단선을 만들지 않습니다.
- 같은 원본·범위·좌표 변환의 유효한 표시 파일은 다시 만들지 않고 재사용합니다. 조사구역이 바뀌면 **지적도**를 다시 눌러 새 5km 범위를 준비합니다.
- 취소·실패·조사 전환 시 기존 지도는 유지합니다. 인터넷과 공식 VWorld 서비스가 필요하며 최초 다운로드 시간은 파일 크기와 연결 상태에 따라 달라집니다.

공식 자료: [VWorld 연속지적도](https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?dsId=30563).
