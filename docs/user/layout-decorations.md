# 조판 장식 이동과 크기

1. 조판 아래의 **항목 이동**을 누른다.
2. 용지의 축척자·축척 글자·좌표계·방위표 중 하나를 클릭해 선택한다.
3. 선택한 항목을 끌어 위치를 바꾼다.
4. 오른쪽 **도면 정보 → 선택 항목 크기**를 조절한다. 기본 100%, 범위 25~200%다. 50%로 낮추면 글자·그림도 함께 작아진다.

축척자는 지도와 연결되어 있다. 크기를 줄이면 눈금 사이 거리도 줄어들며 숫자가 함께 바뀐다. 지도 축척 자체는 크기 조절로 바뀌지 않는다. 지도 축척을 바꾸면 거리 표시를 다시 계산한다.

지도 새로고침이나 축척 변경으로 장식의 위치를 기본 자리로 되돌리지 않는다. 용지 방향/크기를 바꿀 때는 기존 동작대로 용지 안에 위치를 조정한다. 크기 조절은 입력칸 밖을 클릭한 뒤 Ctrl+Z로 되돌릴 수 있다.

작은 크기에서는 글씨도 작아진다. 출력 전에 **PDF 내보내기** 결과를 확인한다. 기존에 전달한 포터블 폴더는 개발용 Release 빌드와 별개이며 새 빌드가 자동으로 복사되지 않는다.
