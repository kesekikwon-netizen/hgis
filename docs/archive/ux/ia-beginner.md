# 초보자 IA — 고고학 전용 HGIS

> **설계 기록, 현재 UI 아님.** 2026-09-29 보관(F215). 왼쪽 7단계 레일·오른쪽 도움 패널·[도움말] 단추·새 조사 기본 EPSG:5179·그리는 중 속성 팝업은 현재 앱에 없거나 사용자 결정으로 뒤집혔다. 현재 사용법은 [docs/user/quick-start.md](../../user/quick-start.md), 제품 규칙은 `AGENTS.md`.

**기본 모드:** 초보자 (7단계 레일만 노출)  
**언어:** 한국어 1차  
**숨김:** Mesh, 3D, GRASS, 일반 GIS 메뉴 정글

## 7단계

### 1. 새 조사 만들기
- **목표:** 조사 이름·저장 위치·기본 좌표계(5179)로 GPKG 프로젝트 생성
- **성공:** `survey.gpkg` + 빈 도메인 레이어가 열림
- **도구:** 마법사 다음, 폴더 선택

### 2. 배경지도·지적 불러오기
- **목표:** 수치지형/지적/영상 등 배경 추가
- **성공:** 배경 레이어가 캔버스에 보임
- **도구:** 파일 열기, (선택) 온라인 배경

### 3. 조사구역 그리기
- **목표:** 발굴·조사 범위를 **폴리곤**으로 작성
- **성공:** `survey_area`에 폴리곤 ≥1, 저장됨
- **도구:** 그리기 시작/저장/종료, 스냅 토글

### 4. 유구 그리기 / 단면선
- **목표:** 유구 면·선, 단면 기준선 작성 + 종류·시대
- **성공:** feature 레이어에 객체 + 필수 속성
- **도구:** 유구 면, 유구 선, 단면선, 속성 팝업

### 5. GPS 기준점 등록
- **목표:** 절대좌표 기준점 ≥2 + 측지 메타
- **성공:** control_points ≥2, datum/ellipsoid/projection 채움
- **도구:** 점 추가, CSV/RTK 가져오기

### 6. 도면 검수
- **목표:** 법령형 체크리스트 통과
- **성공:** error 0건 (warn은 확인 후 진행 가능)
- **도구:** 검수 실행, 항목별 이동

### 7. 제출 패키지
- **목표:** PDF 도면 + SHP 등 제출 폴더 생성
- **성공:** 폴더에 PDF·SHP·README_제출.txt
- **도구:** PDF 마법사, SHP 인코딩 선택, 내보내기  
- **차단:** 검수 error 남으면 하드 블록

## 전문가 설정 (접힘)

- 스냅 고급, CRS 전문가, DXF 입출력, 스캔 평면도 지오레퍼런스, 심볼 세부, 레이아웃 수동 편집

## 각 단계 성공 기준 (한 줄)

1. 새 GPKG 조사 열림  
2. 배경 보임  
3. 조사구역 폴리곤 저장  
4. 유구/단면 속성 포함 저장  
5. 기준점 2+ 메타 완료  
6. 검수 error 0  
7. 제출 폴더 생성됨
