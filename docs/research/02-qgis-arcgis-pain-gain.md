# QGIS / ArcGIS 고통·강점 → ka-hgis UI 대응표

> **조사 메모, 현재 UI 아님.** 아래 제안 중 7단계 레일(6행), 새 조사 5179 고정(8행), 그리기 완료 시 필수 속성 팝업(10행), 코치마크·더블클릭 옵션(2행), 유도 토스트(12행)는 구현하지 않았거나 사용자 결정으로 뒤집혔다: 작업 좌표계는 5186/5187(기본 5187), 5179 는 제출 전용, 그리는 동안 팝업 없음. 현재 사용법은 [docs/user/quick-start.md](../user/quick-start.md).

필드 고고학(발굴 도면) 관점에서 ArcGIS 이주민과 QGIS 기본 UI의 간극을 정리하고, **고고학 전용 HGIS** 화면 요소로 흡수한다.

## 표

| # | pain (고통) | keep (살릴 점) | ka_hgis_ui_fix (구체 UI) |
| --- | --- | --- | --- |
| 1 | 편집 모드(Toggle Editing)가 숨겨져 초보가 그리기를 시작 못함 | QGIS 트랜잭션·되돌리기 모델 | 대형 버튼 **「그리기 시작 / 저장 / 종료」** |
| 2 | 폴리곤 완료가 우클릭이라 ArcMap 더블클릭 습관과 충돌 | 정밀 버텍스 편집 | 캔버스 **코치마크** + 설정 **「더블클릭 완료」** 옵션 |
| 3 | Define Projection vs Project(재투영) 혼동으로 좌표 사고 | 강력한 재투영·datum 변환 | **「이름만 지정(위험)」** / **「좌표 변환」** 이색 버튼 분리 |
| 4 | 인쇄 레이아웃이 별세계라 도면 진입이 어려움 | QgsPrintLayout 품질 | 단계 **「도면 만들기」** 원클릭 마법사 |
| 5 | SHP 한글 인코딩(UTF-8/EUC-KR) 깨짐 | OGR 다중 포맷 | **제출 패키지** 인코딩 선택 + 테스트 필드 |
| 6 | 툴바·메뉴 과다(Mesh/3D/GRASS…) | 필요 시 전문가 기능 | 기본 **7단계 레일**, 나머지는 **「전문가 설정」** 접기 |
| 7 | 스냅 설정을 찾기 어려움 | 고급 스냅·토폴로지 | 유구 그리기 단계에 **스냅 ON 기본** + 간단 토글 |
| 8 | 프로젝트 CRS vs 레이어 CRS 이중 구조 혼란 | 온더플라이 재투영 | 상태바 **항상 EPSG 표시**, 새 조사 시 **5179 고정 기본** |
| 9 | 스캔 평면도 지오레퍼런스 단계 김 | Georeferencer 엔진 | **「스캔 평면도 맞추기」** 마법사 (GCP≥2) |
| 10 | 속성 입력이 기하 완료 후 잊힘 | 폼·위젯 | 그리기 완료 시 **종류·시대 필수 팝업** |
| 11 | ArcMap Editor 툴바 근육 기억 상실 | Advanced Digitizing 동등 기능 | 용어 병기: 스케치≈그리기, Reshape≈형태수정 |
| 12 | 레이어 없는 상태에서 도구 클릭 → 무반응 | 명시적 레이어 모델 | 도구 클릭 시 **「새 조사 만들기」로 유도** 토스트 |

## 설계 원칙

1. **GIS 용어 최소화**, 발굴 업무 용어 우선  
2. 위험 작업(CRS 이름만 지정, 검수 실패 제출)은 **색·확인 대화상자**  
3. QGIS 엔진 능력은 유지, **진입 경로만 고고학화**
