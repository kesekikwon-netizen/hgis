## 지적 GetMap (확인된 사실)

- 키 + `domain=localhost`로 GetCapabilities에 `lp_pa_cbnd_bonbun` 있음. bbox는 **EPSG:4326만**.
- 약 600m 창 EPSG:3857 GetMap은 주황 필지선 PNG.
- 수십 km 창은 투명 빈 PNG. 그래서 한국 전체 축척에서는 지적 선이 안 나온다.
