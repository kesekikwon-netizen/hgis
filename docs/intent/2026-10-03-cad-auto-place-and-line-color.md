# 요청 기록: 좌표가 있는 도면은 자동으로 제자리에, 로컬 좌표 도면만 정합 · 선으로 된 지도 선 색 바꾸기

- 날짜: 2026-10-03
- 상태: 완료
- 관련 문서: docs/superpowers/specs/2026-10-02-cad-crs-import-design.md (10-02 결정 2번 「조사 지역이 없거나 애매하면 목록에서 고른다」를 이 기록이 바꾼다)

## 요청 원문
> 그리고 선의 색을 조정할수있게하라.
> 창을 유지하되 맞으면 창을 끌수있게하라.
> 내말은 이전에서는 도면을 넣으면 자동으로 배치가 되었다 왜 배치가 안되나 자동으로. 도면의 좌표걔를 사용자가 모르는데 저창으로 사용자에게 배치하라고 하면 어떻게 하나 이전에서 자동인식이 되었는데
> 이것에 대한 정보가 없는건가 이전 사용자요청들이?
> 사용자요청 : 조사구역 사용자의 화면위치인식해서 자동으로 하면안되는건가? 실제 조사구역이 사업자의 도면이 읽어들여와야 조사구역 표시가 가능한데 반대로 되면? 자동으로 인식이 안되는것만 정합으로 하게만들면? 현재 5174호 정확하게 위치가 들어왔다. 그리고 참조지도로 읽어들여와야하나 이게? 그러면 선의 색을 조정할수없게 되어버린다 참조지도도 도형 색을 조정 할수있게 하면 안되나?

2026-10-03 목표로 덧붙임:
> 사용자는 이도면의 위치 좌표계를 모른다는 가정을 하고 시작을 하라. 그리고 좌표계가 도면안에 있다면 그걸 적극사용해야한다 위치를 만약에 이도면이 일반공사업체 로컬 좌표계를 사용중이라면 이것은 정합밖에는 답이없다. 그게아니라면 좌표계가있는 도면이라면 이것은 자동으로 계산이 되게 해서 들어가야한다 최대한 사용자가 덜 개입하게 해서 자동화를 해야한다. 선색은 사용자가 직접 바꿀수있게하라. 선으로 된지도는 사용자가 색을 바꿀수있게하라.

## 문제
- 조사구역이 아직 없고 지도가 한반도 전체를 보면 「도면 좌표계 고르기」 창이 뜬다. 사용자는 도면 좌표계를 모른다.
- 실제 순서는 사업자 도면을 먼저 올리고 그것을 보고 조사구역을 그린다. 지금 자동 판단은 조사구역이나 폭 50 km 이하로 확대한 화면이 있어야 해서 순서가 거꾸로다.
- 도면이 스스로 밝힌 좌표계(파일 이름의 「_5187」, 함께 온 .prj, 도면 글자의 「EPSG:5186」·「GRS80 중부원점」)를 쓰지 않는다.
- 참조 지도·지적도는 「도형 색」 창이 막는다(「지적도·배경 지도는 여기서 색을 바꾸지 않습니다」). 도면 선은 CAD 원래 색(`color` 칸)으로만 그려진다.

## 바라는 결과
- 사용자에게 좌표계를 묻지 않는다. 좌표계 고르기 창을 없앤다.
- 로컬 좌표 도면(원점 가까운 숫자, 한국 밖)만 정합으로 간다.
- 좌표가 있는 도면은 아래 순서로 단서를 찾아 자동으로 제자리에 올린다. 앞 단서가 자리를 하나로 정하면 거기서 끝, 여럿으로 줄이면 다음 단서로 더 줄인다.
  1. 도면이 밝힌 좌표계: 원본 옆 .prj, 파일 이름의 EPSG 번호, 도면 글자의 EPSG 번호·좌표계 이름.
  2. 같은 파일(이름만 다른 복사본 포함)을 전에 제자리에 올린 기억.
  3. 조사구역, 그다음 지도에 이미 있는 위치 자료(받은 지적도, 좌표로 올린 다른 도면)에서 10 km 안.
  4. 지금 지도 화면 안.
  5. 파일 이름·도면 글자·조사 파일 이름의 지명(시·도, 시·군·구, 읍·면·동)이 가리키는 시·도.
  6. 그래도 여럿이면 최근에 맞았던 좌표계, 그다음 기본 순서로 가장 그럴듯한 자리에 올리고, 위쪽 알림에 「다른 위치로 바꾸기」(지역 이름 목록)를 둔다.
- 한 번 확실하게(또는 알림에서 바꿔) 제자리에 올린 도면은 앱이 기억한다.
- 선으로 된 지도는 사용자가 「도형 색」에서 선 색·굵기를 바꾸고 「원래 색으로」 되돌릴 수 있다. 저장하면 조사 작업공간에 남는다.

## 영향받는 곳
도면 불러오기(파일함, 끌어놓기, 정합 단추), 위쪽 도면 알림, 레이어 「면·외곽선 색」·오른쪽 「스타일」 탭, 참조 지도·지적 레이어.

## 지켜야 할 것
- 원본 DXF·DWG·.prj는 읽기만 한다. 작업 좌표계는 5187·5186. 도면은 참조 지도에 둔다.
- 단서로 정해지지 않은 자리는 알림에서 「가장 그럴듯한 자리」라고 밝히고 한 번에 바꿀 수 있게 한다(04:01 부산 앞바다 같은 일을 말없이 두지 않는다).
- 토양도·지질도처럼 면을 색으로 채운 지도(공식 범례)와 영상 지도(위성·지형·VWorld 지적 그림)는 색을 바꾸지 않는다.
- 조사 데이터 레이어의 「도형 색」 동작은 그대로 둔다.

## 이번에 하지 않는 것
- DWG 변환 뒤 한글 글자(지번·면적)가 깨지는 문제(따로 요청받으면).
- 도면 글자 색, 점 색.

## 미정 질문
1. 선 색을 바꾸면 어떻게 바뀌나 — 추천: 레이어의 선을 모두 고른 한 색으로(굵기도), 「원래 색으로」로 되돌림 — 사용자 답: 「선색은 사용자가 직접 바꿀수있게하라」(추천대로)
2. 색을 바꿀 수 있는 범위 — 추천: 도면과 직접 불러온 벡터 — 사용자 답: 「선으로 된지도는 사용자가 색을 바꿀수있게하라」 → 선 레이어, 외곽선만 그리는 면(지적), 도면의 면
3. 도면을 참조 지도에 그대로 둘까 — 추천: 그대로 — 사용자 답: 반대 없음(추천대로)

## 확인 방법
1. 「테스트」 조사(조사구역 없음)에서 지도를 영천 근처로 옮기고 test1.dwg를 넣으면 창 없이 가수리 제자리에 올라간다.
2. 파일 이름에 「_5187」이 붙은 DXF는 지도가 어디를 보든 창 없이 제자리에 올라간다. 로컬 좌표 도면만 정합 화면으로 간다.
3. 참조 지도의 도면 「선」(또는 받은 지적도)을 우클릭 → 「면·외곽선 색」에서 색을 바꾸면 선 색이 바뀌고, 저장한 뒤 다시 열어도 그 색이다.
