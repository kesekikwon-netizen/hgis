## 문제
- 버튼을 누르면 뜨는 창마다 크기, 버튼 높이·순서, 글자 크기가 제각각이다(코드 조사: 창 폭 280~480, 크기를 정하지 않은 창 9개, 버튼 높이 28·30·34·36·40, pt와 px 혼용).
- 첫 시안은 실제 화면을 보지 않고 코드 숫자와 목업만으로 그렸다. 사용자가 실제 확인을 요구했다. 지금 시안(캔버스 14판)은 앱의 아이콘 파일(data/icons), 실제로 잰 리본 크기(타일 50·아이콘 32·이름 13), 실제 시작 화면·지도 화면 캡처, 코드에서 읽은 창 10종의 항목과 문구로 그렸다. 대화창을 직접 열어 찍지는 못했다(마우스 조작 거절).
- 사용자는 지금 모양(9-29 목업 기준)을 넘어 색부터 모양까지 더 나은 디자인이 가능한지, 앱을 처음 켤 때 움직이는 시작 화면으로 어떻게 달라질 수 있는지 보고 싶어 한다.

## 바라는 결과
- 실제 화면 캡처와 코드 값에 근거한, 지금 화면과 개선안을 나란히 볼 수 있는 디자인 시안(캔버스).
- 색·글꼴·버튼·창 크기 기준과 주요 창의 새 모양, 시작 화면 모션 안.
- 사용자가 고른 뒤에야 앱 코드에 적용한다.

## 영향받는 곳
- 화면: 리본 버튼으로 뜨는 모든 창, 진행 창, 알림 창, 시작 안내(KaStartupSplash), 홈·지도 화면의 색과 글꼴.
- 조사 자료(GPKG)와 기능 동작은 바꾸지 않는다.

## 지켜야 할 것
- 9-29 목업이 지금의 기준 모양이다. 새 모양은 사용자가 시안을 보고 고른 것만 기준을 바꾼다.
- 이미 정한 것: 이름 Strata, 한 줄 리본, 맑은 고딕, 레이어 목록 10 px, 상태줄 그대로, 「정합」 라벨, 시작은 홈 화면만.
- 리본은 지금 앱 그대로: 아이콘 크기, 아이콘 아래 기능 이름, 아이콘 모양(data/icons의 지금 아이콘 파일)을 바꾸지 않는다(2026-10-03 「전체시안에 아이콘만있나 아이콘기능의 이름은? 현재앱은 이렇게 되어있는데」, 「아이콘 모양도 지금만 좋게 한다」). 색만 새 색을 입힌다.
- 그리는 동안 팝업을 늘리지 않는다. Windows 「애니메이션 효과 표시」를 끈 PC에서는 모션을 멈춘다(지금 코드가 이미 지킨다).
- 같은 날 main에 들어간 결정(30a8535)을 따른다: 조사구역 그리기 창은 작게, 오른쪽 판은 속성·스타일 두 탭.
- 시작 화면의 저작권·자료 안내 두 줄과 GPL 고지는 문구 그대로 둔다. Anthropic의 로고·이름·전용 글꼴은 쓰지 않는다(색과 분위기만).
