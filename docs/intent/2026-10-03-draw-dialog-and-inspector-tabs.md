# 요청 기록: 조사구역 그리기 창 줄이기와 오른쪽 속성·스타일·사진 탭 정리

- 날짜: 2026-10-03
- 상태: 완료
- 관련 문서: 없음

## 요청 원문
> 지금 조사구역 그리기를 하면 창이 너무 크게 나타나는것 같지않나? 그리고 속성스타일도 속성 스타일 사진 이기능이 뭔지 이해도 안가고 왜있는지도 모르겠다. 속성도 안나오고 스타일은 누르면 쓸때없는 버튼만 하나더 나타나고 바로 수정 편집할수있는거도 아니고 사진도 그렇다 사진을 누르면 뭘 업로드하라는건지 아니면 어떻게 하라는건지 뭘이야기하는건지 왜만든건지 이해가 안된다.  이것을 수정하던지 보완하던지 없애던지  하라.
>
> (스크린샷 3장: 「조사구역 그리기 설정」 창, 오른쪽 「선택한 유구」의 사진 탭과 스타일 탭)
>
> 2026-10-03: 추천진행

## 문제
- 「조사구역 그리기 설정」 창이 크다(화면 기준 약 692×683). 큰 색 버튼 8개(2줄), 굵기 버튼 4개, 창 제목을 되풀이하는 제목·설명, 미리보기 칸이 쌓여 있고 크기를 정한 곳이 없다. 목업에는 이 창이 없다.
- 속성 탭: 지도에서 도형을 정확히 하나 골라야만 기록이 나온다. 방금 그린 도형은 저절로 골라지지 않아 그린 뒤에도 비어 있다. 조사구역을 골라도 조사명·유적명이 안 나온다.
- 스타일 탭: 설명 한 줄과 「레이어 스타일 편집…」 버튼뿐이고, 버튼은 고른 도형이 아니라 왼쪽 목록에서 강조된 레이어의 「도형 색」 창을 따로 연다.
- 사진 탭: 앱에 사진을 저장하는 기능이 없다. 늘 같은 문장만 보이고, 조사카드에 이미 있는 「사진」 칸 대신 메모에 적으라고 잘못 안내한다.
- 세 탭은 9-29 목업 7쪽에서 왔지만 목업에는 속성 탭 내용만 그려져 있고, 스타일·사진 내용은 개발 쪽이 정했다. 사진 탭은 사용자에게 물은 적이 없다.

## 바라는 결과
- 조사구역 그리기 창이 작아지거나(또는 뜨지 않고) 바로 그릴 수 있다.
- 오른쪽 판의 탭마다 쓸모가 분명하다: 쓸모없는 것은 없애고, 남기는 것은 그 자리에서 바로 보이고 고쳐진다.

## 영향받는 곳
- 화면: 조사구역 그리기 창(KaSurveyAreaDialog), 오른쪽 「선택한 유구」 판(KaInspectorPanel·KaFeatureCard).
- 기능: 조사구역·유구 그리기 직후 상태, 레이어 색·굵기 바꾸기. 조사 자료(GPKG) 구조는 바꾸지 않는다.

## 지켜야 할 것
- 조사구역 레이어는 LayerOps 경로로만 만들고 layer_key 는 survey_area 그대로. 자동 저장 없음(편집은 Ctrl+S 까지 저장 안 됨, 되돌리기 한 단계씩).
- 그리는 동안 팝업을 늘리지 않는다(목업 1쪽 「그리는 동안 팝업 없음」). 목업과 다르게 바뀌는 곳은 이번 사용자 말이 기준이다.
- 바꾸거나 지우는 기존 시험은 커밋에 「시험 변경:」 줄을 쓴다.

## 이번에 하지 않는 것
- 사진을 실제로 붙이는 새 기능(질문 4에서 「만들기」를 고르면 따로 기록).
- 왼쪽 「표시 설정」, 지도 위 투명도 막대, 조사카드 창 자체의 모양.

## 미정 질문
1. 조사구역 그리기 창 — 추천: 작게 줄이기(색은 작은 칸 한 줄, 굵기 한 줄, 되풀이 제목·설명·미리보기 빼기, 이미 구역이 있으면 창 없이 이어 그리기) / 다른 답: 창 없이 바로 그리기(색은 나중에 스타일 탭에서) — 사용자 답: 추천대로
2. 속성 탭 — 추천: 그린 직후 그 도형의 기록을 바로 보여 주고, 조사구역은 조사명·유적명도 보이고 고칠 수 있게 — 사용자 답: 추천대로
3. 스타일 탭 — 추천: 고른 도형의 레이어 색·외곽선·굵기를 탭 안에서 바로 고치고 지도에 바로 보이게(따로 창 없음) / 다른 답: 탭 없애기 — 사용자 답: 추천대로
4. 사진 탭 — 추천: 없애기(사진 저장 기능이 없음. 조사카드의 「사진」 칸은 그대로) / 다른 답: 사진 붙이기 기능 새로 만들기 — 사용자 답: 추천대로

## 확인 방법
- 「조사구역 그리기」를 누르면 작은 창(또는 창 없이) 바로 그릴 수 있다.
- 유구를 하나 그리고 마치면 오른쪽 속성 탭에 그 유구 번호·종류·시대가 바로 보인다.
- 오른쪽 판에서 색이나 굵기를 바꾸면 지도의 그 레이어가 바로 바뀌고, 사진 탭은 (없앴다면) 보이지 않는다.

## 결과
- 조사구역 창: 이름·색 8칸 한 줄·굵기 한 줄·버튼만(앱 테마로 약 540×220, 전 595×552). 구역이 있으면 창 없이 이어 그린다 — 조사 파일 안의 조사구역만, 왼쪽 목록에서 고른 것 먼저(따라 그리려고 연 「조사구역」 파일에는 이어 그리지 않음).
- 속성: 그린 도형의 기록이 바로 보인다(고르지는 않음: 겹친 곳 지우기·나누기·Delete 가 엉뚱한 도형을 쓰지 않게, 코드 검토). 조사구역은 조사명·유적명을 보이고 고친다.
- 스타일: 색 8칸과 굵기를 탭 안에서 바로 바꾸고 레이어에 기억된다. 선으로 된 지도는 오른쪽 클릭 「면·외곽선 색」을 안내. 사진 탭과 그 아이콘은 없앴다.
- 확인: 빌드 0, 관련 시험 23묶음 통과(save_open_erase 포함), 앱 시작 확인 0, 줄 수 검사 0건. 창·스타일 탭은 시험이 앱 테마로 그린 그림으로 확인(지도 탭 실제 클릭 확인은 앱 조작 허락이 없어 하지 못함). 커밋은 이 기록 다음 커밋.
