## 문제
- GitHub 검사 한 번이 70~95분(빌드 45분 + 시험 23분 + 기다림). 새 대화마다 이 PC 첫 빌드가 약 8분.
- c35cdf6에서 처음 초록불이 된 뒤 fd9eca0에서 앱·시험 변경 없이 workflow 시험 2개가 한글 임시 폴더 단계에서만 실패했다(흔들리는 시험). 로그상 두 시험 모두 방금 저장한 조사구역을 앱이 0개로 읽었다.
- 검사의 `--repeat until-pass:2`는 실패를 기록 없이 통과시킨다.

## 바라는 결과
1. 흔들리는 두 시험의 원인을 찾아 고친다(시험 쪽이면 시험, 앱의 진짜 버그면 앱). 검사는 재시도해도 흔들린 시험 이름을 남기고, 기한이 적힌 격리 목록에 없는 실패는 빨간불로 둔다.
2. GitHub 검사에 Ninja + 컴파일 캐시 + /Z7로 빌드하는 실험 갈래를 따로 두어 시간과 캐시 적중을 잰다. 기존 검사 결과에는 영향을 주지 않는다.
3. 이 PC에서 작업 폴더끼리 컴파일 캐시를 나눠 새 대화의 첫 빌드가 빨라지는지 잰다.
4. 시험을 여러 실행기로 나눠 시험 단계 시간을 줄인다.
5. Qt 헤더를 미리 컴파일해 빌드가 빨라지는지 실측하고, 빨라질 때만 남긴다.
