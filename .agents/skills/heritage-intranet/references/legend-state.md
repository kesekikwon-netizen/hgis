# 현재 상태 — 번호 기능 취소, 범례 여러 열만 유지

사용자가 다운로드 시간 증가를 관찰한 뒤 번호 기능을 취소했다. 아래 번호 기능 기록은 제거된 과거 상태다.

- 현재는 KaDrawingStudio.cpp의 fitLegendColumns/configureLegendColumns만 추가되어 있다. 범례 폭/글자 크기로 열 수와 줄바꿈 폭을 정한다. 위치만 바뀌거나 결과가 같으면 갱신하지 않는다.
- 도형 조회, 번호 생성, 레이어 복제, 번호 스타일 override, 번호 캐시/타이머는 제거됐다. HeritageSiteLegend는 번호 추가 전 구현이며 기존 QGIS 범위 필터를 유지한다.
- 사용자 지시 없이 번호 기능을 다시 넣지 않는다. 실제 다운로드 지연 원인은 확정되지 않았고 이번 제거로 속도가 개선됐다고 측정 전 주장하지 않는다.

# 최신 변경 — 2026-09-13 도면 번호와 여러 열

사용자가 명시적으로 도면 번호/번호와 유적명 범례/폭에 따른 자동 열을 요청하여 구현했다. 아래 초기 조사 기록과 구분한다.

- HeritageSiteLegend의 prepareLayout는 도면 범위 안 카테고리에 종류별 번호를 부여한다. 도면 스타일 override만 바꾸고 원본 SHP/주 지도 명칭은 보존한다. RuleKey는 유지한다.
- 캐시는 범위/CRS/축척/자료 순서/원본 스타일/원본 파일 시각을 포함한다. 범례 트리가 재생성되면 캐시의 값만 새 노드에 재적용한다. 노드 포인터를 캐시하지 않는다.
- KaDrawingStudio는 숨김 시 번호 계산을 하지 않는다. 표시 시 갱신하고 PDF 저장 직전에도 반영한다. 범례 크기 신호는 fitColumns만 호출한다. 덧지도에 동일한 번호 스타일을 연결한다.
- 이름 필드가 없거나 기존 2,000개 제한으로 단일 심볼이 된 유산은 번호 대상에서 제외된다. 일반 categorized 유산 경로를 구현했다.
- Release 빌드와 코드 검토 완료. PID 20244 앱 실행. 실제 도면/PDF 및 속도는 사용자 확인 전이며 다운로드 성공 검증과 구분한다.

# 도면 범례 상태 — 2026-09-13

## 확인된 현재 연결

- `LayoutService::tuneSheetLegend`는 `setLegendFilterByMapEnabled(true)`를 설정하고 연결 지도 기준의 수동 범례 트리를 만든다.
- `KaDrawingStudio::applyLegendSettings`는 범례를 실제 도면 지도에 연결한다.
- `HeritageSiteLegend::createLayerTreeModelLegendNodes`는 도면에서는 QGIS 기본 벡터 범례 노드를 반환한다. 카테고리 RuleKey가 유지된다.
- 설치 QGIS는 4.3.0-Master, 패키지 commit `5073f6f11ec`다. 아래 근거는 이 버전에 대한 것이므로 이후 SDK 변경 시 다시 확인한다.

[QGIS 공식 범례 구현](https://github.com/qgis/QGIS/blob/5073f6f11ec/src/core/layout/qgslayoutitemlegend.cpp)에서 필터 대상은 명시적 `filterByMapItems()`와 `linkedMap()`을 포함한다. 지도 `visibleExtentPolygon()`을 사용하며 범위와 회전 변경에 자체 갱신을 연결한다. `setFilterByMapItems({map})`를 추가하거나 별도 타이머를 만들 필요가 있다는 근거는 없다.

[QGIS 공식 범례 모델](https://github.com/qgis/QGIS/blob/5073f6f11ec/src/core/layertree/qgslayertreemodel.cpp)은 hit-test의 RuleKey로 항목을 거른다. 같은 자료 유형의 색이 같다는 이유만으로 모든 유적이 남는다고 단정하지 않는다.

## 범위와 길이를 구분

현재 소스에서 범위 필터 누락은 발견하지 못했다. 실제 사용자의 도형/도면으로 출력 검사를 수행한 것은 아니므로 모든 항목이 정확하다고 검증 완료를 주장하지 않는다.

범례가 길 수 있는 별도 이유는 같은 유적이 지정유산/보호구역 등 여러 레이어에 있거나, 넓은 조사구역 폴리곤이 도면과 겹치는 경우다. 화면에서 긴 항목만 보고 안동시 전체 목록이라고 하지 않는다. 일부만 걸친 유적도 범위 안 항목이다.

중복 명칭 통합은 분류 의미를 바꿀 수 있고 여러 열 배치는 별도 표시 기능이다. 사용자가 선택한 범위 안에서 한 가지씩 바꾼다. 도면 번호 생성은 자동으로 재도입하지 않는다.
